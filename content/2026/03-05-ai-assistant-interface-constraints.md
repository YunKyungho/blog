# #29. AI 비서의 인터페이스 제약과 실용성 재고

*2026-03-05*

## TL;DR
- AI 비서(도비)의 실제 활용 환경에서 인터페이스 제약 사항 정리
- 텔레그램 중심의 원격 소통 vs 로컬 GUI 직접 조작의 실용성 차이
- 백그라운드 처리 + 결과 전달 중심으로 역할 재정의

## 발견된 제약 사항

### 물리적 접근성
- 맥미니는 원격으로 사용하는 환경
- 직접적인 GUI 조작이나 로컬 앱 실행은 실용성이 떨어짐
- 유일한 소통 채널: 텔레그램 메신저

### 실용적 vs 비실용적 기능

**높은 실용성:**
- 웹 검색 및 정보 수집
- 텍스트 처리 및 요약
- 일정/리마인더/할일 관리
- 백그라운드 파일 생성 후 공유
- 크론 기반 자동 알림

**낮은 실용성:**
- GUI 직접 조작 (Raycast, Alfred 등)
- 화면 공유나 원격 제어
- 실시간 상호작용이 필요한 로컬 앱

## 역할 재정의

### Before: "모든 것을 할 수 있는 만능 비서"
- 로컬 환경 직접 제어
- GUI 자동화
- 실시간 상호작용

### After: "백그라운드 처리 + 텔레그램 전달 특화"
- 정보 수집 후 요약 전달
- 스케줄 기반 자동 작업
- 텍스트/문서 생성 및 공유
- 원격 모니터링 및 알림

## 실제 적용 사례

### 블로그 자동 포스팅
- 새벽 1시에 백그라운드 실행
- 의미있는 작업 스캔 → 포스트 생성 → Git 푸시
- 완료 후 텔레그램으로 결과 알림

### 모닝 브리핑
- 날씨, 일정, 뉴스 수집
- 하나의 메시지로 정리하여 전달
- GUI 없이도 유용한 정보 제공

## 교훈

AI 비서의 진정한 가치는 "무엇을 할 수 있는가"보다 "어떤 환경에서 실제로 유용한가"에 있다. 

물리적 제약을 인정하고 그 안에서 최대 효율을 내는 것이 더 현실적이고 지속가능한 접근법이다.
